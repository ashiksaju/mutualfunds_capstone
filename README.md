# Bluestock Mutual Fund Analytics

## Project Overview

Bluestock Mutual Fund Analytics is an end-to-end data analytics project developed to analyze mutual fund performance, investor behavior, portfolio characteristics, and financial risk using Python, SQLite, SQL, and Power BI.
The project demonstrates the complete analytics workflow, from raw data ingestion to interactive business dashboards.

## Objectives

- Build an automated ETL pipeline
- Clean and validate mutual fund datasets
- Store processed data in SQLite
- Perform exploratory data analysis (EDA)
- Calculate advanced financial metrics
- Build interactive Power BI dashboards
- Generate business insights
- Recommend funds based on risk appetite

## Technologies Used

- Pandas
- NumPy
- SQLite
- SQL
- Power BI
